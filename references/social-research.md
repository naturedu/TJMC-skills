## 采集路径

使用当前检索工具或用户授权的浏览器会话。有连接器时先确认它是否支持读帖，不能把电商物流 API 当笔记搜索接口。无需为了普通检索强制安装插件。

站内搜索优先；搜索引擎补查公开索引，写入经验库前尽量打开原帖。遇登录、验证码、付费或无法读取的页面，记录阻碍并继续官网可核实的部分。需要登录由用户在平台正常界面完成，不索取 Cookie、验证码或令牌，不绕过访问控制。

## 记录字段

```text
主题 / 名称 / 所属校区或片区
原帖标题 / 作者公开昵称 / 原始链接
发布日期（未展示则如实注明）/ 访问日期
读取深度：全文、部分正文、图像、评论、仅摘要
简短转述 / 支持哪些具体事实
具体分店或建筑 / 价格与计价单位 / 时间适用范围
交叉核验链接 / 冲突说法 / 证据状态
```

只记录指南需要的公开信息，不采集普通用户联系方式、取件码、住址或宿舍房号。地图图片保留出处及原链；可读截图可提取地标，看不清的文字和方位标为不确定。原创示意图须基于已核验位置并标注“示意图，非导航地图”。

## 公众号成稿

按请求可组织为“怎么找路—怎么取快递—附近怎么吃—课程怎么学—往年题怎么找—保研去哪看”，也可只写指定章节。来源和核验日期放条目旁或末尾；分清个人偏好、历史经验与官方规则。没有读到原帖，不写“我搜集了小红书同学们的推荐”。
