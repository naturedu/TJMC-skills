## 工具路径

1. 使用已安装且能完成笔记/视频搜索的连接器；没有合适工具时用正常浏览器页面。沿站内搜索、作品详情、作者和合集的可见入口读取，不猜账号 ID 或作品 ID。
2. 浏览器受限时补查公开索引，查询写作 `site:douyin.com/video "同济医学院" "主题"`，注意 `site:` 的冒号；可使用检索工具的 `douyin.com` 域名过滤。搜索页只是发现入口，不能代替作品原链。
3. 打开实际检出的原页。能读到标题、简介、字幕、定位，就分别记录；只显示“加载中”或空正文，留存索引线索并记录限制。遇登录/验证走正常平台界面，不索取用户令牌或绕过限制。
4. 没有播放或未见具体画面时，不写“视频中可以看到”。只读简介就总结简介；只有分段观看过的视频才记录对应时间戳。自动字幕注明转写性质，路线、店名和数字需回看画面或官方资料。
5. 存原链接、作品 ID 和简短转述即可。除非用户明确需要且有权获取，不批量下载原视频、去水印、复制完整字幕或转存到其他平台。

## 筛选与去重

- 收录：作品主体或足够明确的地点、院系、路标能定位武汉同济医学院；周边店铺可以单列“周边”，但不能把广告的“紧邻”当距离测量。
- 待核验：只有标题／索引、不能读原文、城市校区不明、广告自述、年份不明。此类条目有价值但不直接成为校园事实。
- 排除本校知识库：上海同济、华科主校区、其他医学院、仅评论命中关键词、没有学校归属的通用题库。附属医院医疗新闻可另列扩展主题，不能代替校园生活材料。
- 一个作品 ID 记一条；分享链接与完整链接指向相同作品时合并。转载同一段素材保留作者和出处关系，不计作多份独立证据。
- 官方账号身份须看认证说明或官网互链。账号名称写“同济”或头像像校徽，不足以判定校方身份。

## 如何报告“尽量收全”

报告实际检索的主题、去重后候选数、原页可读数、观看数和仍空缺的类别。站内登录态、个性化排序、删帖、检索索引及作品权限都会影响覆盖，不能把当前结果数称为平台总数。

对同一主题已经尝试校名与一个相关地标/同义词、且继续出现相同无关结果时，记下缺口并转下一个主题；不持续刷新空页面或生成一堆猜测链接。用户给出新分享链接、新地点或正常可用会话后再补采。检索记录是范围说明，不证明内容不存在。

更新 [来源索引](douyin-source-index.md) 时保留原来的证据状态。只有看到新证据才提升为“简介已读”或“片段已看”，不能因为再次访问了网址就提高可信度。官网仍承担地图、教务和招生政策的核验作用。
