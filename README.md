## 安装到 Codex

1. 下载本仓库并解压。
2. 将**直接包含 `SKILL.md` 的目录**命名为 `tjmc-skills`，复制到个人技能目录。
3. 确认最终路径是 `~/.codex/skills/tjmc-skills/SKILL.md`。Windows 对应 `%USERPROFILE%\.codex\skills\tjmc-skills\SKILL.md`，注意不要多套一层同名目录。
4. 在 Codex 中调用 `$tjmc-skills`；如已有同名技能，更新前先备份自己的修改。

可以这样问：

```text
用 $tjmc-skills 找同济医学院校园地图和快递查询入口。
用 $tjmc-skills 整理我这一届适用的保研官网与通知。
用 $tjmc-skills 查国家奖学金、裘法祖奖学金和公卫学院求职渠道。
用 $tjmc-skills 比较同济校区附近的秋果酒店，给出来源和待核实项。
```

技能入口见 [SKILL.md](SKILL.md)。需要查询最新网页时，运行环境须具备相应检索或浏览能力；这个资料包本身不会自动更新网页、登录账号或发布内容。
